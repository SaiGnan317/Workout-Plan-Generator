# Workout Plan Generator

A simple C program that generates personalized workout plans based on the user's fitness goal, fitness level, and preferred body part.

### Features

* Strength, endurance, and flexibility plans
* Beginner, intermediate, and advanced levels
* Upper, lower, and full-body workouts
* Displays exercises with sets, repetitions, or duration

### Concepts Used

C Structures, Functions, Conditional Statements, String Handling, and User Input.
